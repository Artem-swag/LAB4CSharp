# Задание 1 (List)

## Задача 1

### Текст задачи
Составить программу, которая удаляет из списка L все элементы с указанным значением.

### Алгоритм решения
1. Принимаем на вход список `List<int> L` и искомое значение `value`.
2. Запускаем цикл по списку с конца (от последнего индекса к нулевому). Это позволяет избежать смещения индексов при удалении.
3. Если текущий элемент равен `value`, удаляем его методом `RemoveAt(i)`.
4. Возвращаем измененный список.

# Задание 2 (LinkedList)

## Задача 2

### Текст задачи
В списке L переставить в обратном порядке все элементы между первым и последним вхождениями элемента E, если E входит в L не менее двух раз.

### Алгоритм решения
1. Ищем первое и последнее вхождение элемента `E` в `LinkedList<int>`. Если вхождений меньше двух, список не меняется.
2. Запоминаем указатели (`LinkedListNode`) на первое и последнее вхождение.
3. Проходим от первого вхождения до последнего и сохраняем промежуточные элементы во временный список `List<int>`.
4. Снова проходим между границами, но записываем значения из временного списка в обратном порядке.
5. Возвращаем измененный список.

# Задание 3 (HashSet)

## Задача 3

### Текст задачи
Есть перечень фильмов. Определить для каждого фильма, какие из них посмотрели все n зрителей, какие — некоторые из зрителей, и какие — никто из зрителей.

### Алгоритм решения
1. Задаем эталонный перечень всех фильмов в виде `HashSet<string>`.
2. Считываем количество зрителей `n`. Для каждого зрителя создаем свой `HashSet<string>`, в который он вводит просмотренные фильмы (с валидацией по эталонному списку).
3. Для поиска фильмов, которые смотрели **все**: создаем копию эталонного множества и применяем `IntersectWith` для каждого зрителя.
4. Для поиска фильмов, которые смотрел **хотя бы один**: создаем пустое множество и применяем `UnionWith` для каждого зрителя.
5. Для поиска фильмов, которые **не смотрел никто**: берем эталонное множество и вычитаем из него множество "хотя бы один" (`ExceptWith`).

# Задание 5 (Dictionary)

## Задача 5

### Текст задачи
На вход программе подаются сведения о телефонах всех сотрудников. Сотрудники одного подразделения имеют один и тот же номер телефона (номера отличаются только двумя последними цифрами). Вывести, сколько в среднем сотрудников работает в одном подразделении.

### Алгоритм решения
Оптимальное решение по памяти — не хранить данные всех сотрудников, а считать статистику "на лету":
1. Создаем словарь `Dictionary<string, int>`, где ключ — префикс телефона (первые 5 цифр), а значение — количество сотрудников с таким префиксом.
2. В цикле считываем N строк. Из каждой строки извлекаем телефон, оставляя только цифры.
3. Проверяем, что цифр ровно 7. Отрезаем последние 2 цифры, получаем ключ подразделения.
4. Увеличиваем счетчик для этого ключа в словаре.
5. В конце вычисляем среднее: `N / Количество подразделений`.

# Задание 7 (Перегрузка операторов)

## Задача 1

### Текст задачи
Добавить к классу `LineSegment` перегруженные операции:
* `!` — вычисление длины отрезка (double);
* `++` — увеличение координат границ на 1;
* `int` (явное) — целая часть координаты x;
* `double` (неявное) — координата y;
* `+ int` (лево- и правосторонняя) — сдвиг границ на число d;
* `< int` — попадает ли число в отрезок.

### Алгоритм решения
1. Перегружен унарный оператор `!`: возвращает `Math.Abs(y - x)`.
2. Перегружен унарный оператор `++`: возвращает новый объект `LineSegment` со сдвинутыми на 1 координатами.
3. Перегружены операторы приведения типов: `explicit operator int` возвращает `(int)x`; `implicit operator double` возвращает `y`.
4. Перегружен бинарный оператор `+` для обоих порядков (`LineSegment + int` и `int + LineSegment`).
5. Перегружен оператор `< int` для проверки попадания (использует метод `Contains`). Также реализован `> int` и обязательные `==`, `!=`, `Equals`, `GetHashCode`.
